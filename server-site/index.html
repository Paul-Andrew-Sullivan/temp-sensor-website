Display buttons on the box

Pressing these does the same as pressing the buttons on the box. A sensor whose button is off is not shown on the box's own screen, but is still measured and graphed here. The box picks the change up within half a second.

Last 300 seconds

The graph moves left once a second. Missing data is hatched. A reading beyond the graph's range is drawn as a red line pinned to the top or bottom edge, so a broken sensor never looks like a hot one.

Email or text when it goes out of range

The message goes out once when a sensor crosses a limit, and again only after it has come back inside the range by half a degree. For a text, use your carrier's email-to-SMS address, for example 3195551234@txt.att.net. Mail is sent by the server, so nobody needs to keep this page open.

Save these settings

The ESP32 in the box reads two DS18B20 probes on one-meter leads and posts to this server twice a second. The server keeps the last 300 seconds. A leaner copy of this page, the one the board can serve by itself, is at thermo-esp32.paulandrewsullivan.com.
